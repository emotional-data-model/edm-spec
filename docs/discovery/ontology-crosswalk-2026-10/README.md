# Ontology crosswalk discovery — October 2026

Discovery only. No schema, example or normative doc was modified. Everything here is input to a future v0.9 decision, not a decision.

| File | What it is |
|---|---|
| `REPORT.md` | Findings: grounding percentages, what is uniquely EDM, proposed adds/cuts, one-page v0.9 field list, ranked candidates for the ontology experiment, unverified-claims register |
| `fields.json` | Machine-read inventory of the 57 fields in the five affective domains (type, vocabulary, canonical values, description, profile membership) |
| `frameworks.json` | 39 reference frameworks with citations, fetch status, confidence, and extracted constructs/value sets (167 constructs) |
| `crosswalk.csv` | Full matrix: 242 rows (57 fields + 185 canonical values) × 39 frameworks; cell = relation + target + verification flag |
| `crosswalk.md` | Same mappings as readable per-field tables, plus Gap list A (orphans) and Gap list B (framework constructs with no EDM home) |
| `crosswalk_stats.json` | Counts used in the report |
| `coding-proposal.md` | Recommended code systems per categorical field, code+system+version+text shape, finer/coarser flags, SNOMED code table |
| `theoretical-conflicts.md` | Where the frameworks disagree and how EDM stays neutral |
| `naming-proposal.md` | Domain and field renames, full 57-row old→new table, value renames |
| `v0.9-proposal.md` | Consolidated v0.9 draft: 47-field layout (46 + `narrative.self_position`), opt-in trait profile, text + codings shape, six new fields, vocabulary stub, migration note, MFOEM requests |
| `v0.9-migration-example.json` | `examples/example-full-profile.json` migrated to the draft layout, with the proof that no artifact text changed |
| `mfoem-term-requests.md` | Draft MFOEM new-term issues for awe, gratitude, relief, nostalgia, tenderness, frustration, wonder |
| `vocab/` | EDM vocabulary namespace stub: `edm-vocab-v1.ttl` (SKOS for arc, tether, relationship, memory_type, temporal_profile, need, coping; `skos:*Match` triples from `crosswalk.csv`) and its README |
| `../../../schema/crosswalks/v0.8.3_to_v0.9.0.json` | Draft crosswalk record generated by `scripts/v09_layout.py` (`status: draft`) |

| `mfoem_classes.json` | Full extraction of the MFOEM OWL (version 2025-07-31): every class with CURIE, English label, definition, parents, synonyms, and emotion/mood/affective flags |
| `scripts/` | Generators: `inventory.py` (schema → `fields.json`), `mfoem_extract.py` (OWL → `mfoem_classes.json`), `apply_verification.py` (verification results → `sources/group_*.json`), `merge_frameworks.py` (research extractions + MFOEM + Anthropic list → `frameworks.json`), `crosswalk_data.py` + `decisions_data.py` (the authored mapping and decisions), `crosswalk_build.py` (→ `crosswalk.csv`, `crosswalk.md`, `crosswalk_stats.json`), `v09_layout.py` (field map → draft crosswalk + migration proof), `skos_build.py` (`crosswalk.csv` → `vocab/edm-vocab-v1.ttl`) |
| `sources/` | Raw research extractions per framework group (`group_a_emotion.json` … `group_d_machine.json`), the Anthropic 171-word list as extracted, and `verification_2026-10-17.json` (the secondary-source verification pass applied to the group files by `scripts/apply_verification.py`) |

Reproduction:

```
python -I scripts/inventory.py <repo-root> fields.json
python -I scripts/mfoem_extract.py <MFOEM.owl> mfoem_classes.json
python -I scripts/merge_frameworks.py sources mfoem_classes.json sources/anthropic_171.json frameworks.json
python -I scripts/crosswalk_build.py fields.json frameworks.json .
python -I scripts/v09_layout.py ../../.. ../../../schema/crosswalks/v0.8.3_to_v0.9.0.json v0.9-migration-example.json
python -I scripts/skos_build.py crosswalk.csv frameworks.json vocab/edm-vocab-v1.ttl
```

The verification pass is already applied to `sources/group_*.json`; to re-apply from the consolidated record: `python -I scripts/apply_verification.py sources sources/verification_2026-10-17.json`.

The MFOEM OWL itself (640 KB) is not committed; fetch it from `http://purl.obolibrary.org/obo/mfoem.owl`.
