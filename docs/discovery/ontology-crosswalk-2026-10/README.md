# Ontology crosswalk discovery — October 2026

Discovery only. No schema, example or normative doc was modified. Everything here is input to a future v0.9 decision, not a decision.

**Where v0.9 stands (2026-10-18, close of run 3).** The draft layout is 47 affective fields in five renamed domains, unchanged since 2026-10-17; what the three pre-registered runs changed is how the profiles are formed and what each field may claim. Run 1 (47 fields, 4 extractors, 150 texts), run 2 (the six v0.8.3 core slots under the v0.8.3 text versus v0.9 definitions, three voting extractors) and run 3 (the 19 comparable-tier fields across five further vendor lines through OpenRouter, 5-of-8 rule) were executed and ruled on (R1–R30, each *ruling under delegation, veto by exception*). Under R17 every field carries a comparability class earned in those runs and the profiles are the classes; after run 3 (R18–R28: the coverage clause read with null as an answer, R18; `salience.tether` interpretive, R26) the classes are comparable 18, interpretive 8, null-driven 2, extractor-bound 19, so Essential = comparable (**18**), Extended = + interpretive + null-driven (**28**), Full = 47, computed in `scripts/v09_layout.py` and written into `draft-schema/`. Applied with them: R5 (the never-populated numeric `value` of valence / arousal / urgency / control is deleted), R6 (`meaning` interpretive-attributed), R11–R16 (`harm` and `trigger` carry the run-2 Arm B definitions; `subject`, `integration`, `drive` keep the v0.8.3 wording; `retrieval_cues` is an ordered list capped at three). Run 3 was finished on 2026-10-18 night (Phase A of the overnight instruction): the judge completed on 150 of 150 texts, which closed R20 (`summary` comparable, 8 of 8); the R29 Mistral probe parsed 10 of 10 (the arm's figures are a reasoning-cap artefact; the authorised re-run is deferred to the founder, over the phase cap); the R30 DeepSeek V4 Pro extension and its free-text supplement ran (reasoning off honoured; cheap-tier), so the rule reads 5-of-9 — **12 of 19 hold under the frozen reading, 18 of 19 under R18 (b), `tether` alone fails**; profiles unchanged. The same night: a human anchor on GoEmotions (`experiment-plan-anchor.md`, `experiments/2026-10-18-anchor/`) and the reading-layer discovery (`../reading-layer-2026-10/`). Still open for the founder: the R29 re-run (≈ USD 18.5, founder sets the stop); veto of any ruling; whether the extractor-bound tier stays in Full or moves to `extensions` at the cut; publish of v0.8.4 (R1) and every push. `schema/` and `examples/` are untouched on every branch.

Reproduction:

```
python -I scripts/inventory.py <repo-root> fields.json
python -I scripts/mfoem_extract.py <MFOEM.owl> mfoem_classes.json
python -I scripts/merge_frameworks.py sources mfoem_classes.json sources/anthropic_171.json frameworks.json
python -I scripts/crosswalk_build.py fields.json frameworks.json .
python -I scripts/make_synthetic.py synthetic-examples
node scripts/validate_synthetic.mjs v083 ../../.. synthetic-examples
python -I scripts/v09_layout.py synthetic-examples draft-crosswalk/v0.8.3_to_v0.9.0.json v0.9-migration-example.json migrated-examples
python -I scripts/v09_layout.py --membership   # R17 membership table: class, lead unit and figure per field
python -I scripts/draft_schema_build.py ../../.. draft-schema
node scripts/validate_synthetic.mjs v09 ../../.. migrated-examples draft-schema
python -I scripts/crosswalk_audit.py ../../.. draft-crosswalk/v0.8.3_to_v0.9.0.json crosswalk-audit-2026-10-18.md   # exit 1 if any v0.8.3 field or value lacks a disposition
node scripts/validate_synthetic.mjs v09 ../../.. migrated-examples draft-schema --strict   # shows the trait opt-in failure
node scripts/validate_synthetic.mjs v09 ../../.. migrated-examples/unpruned draft-schema   # profile-agnostic relayout, fails by design
python -I scripts/skos_build.py crosswalk.csv frameworks.json vocab/edm-vocab-v1.ttl
```

The verification pass is already applied to `sources/group_*.json`; to re-apply from the consolidated record: `python -I scripts/apply_verification.py sources sources/verification_2026-10-17.json`.

The MFOEM OWL itself (640 KB) is not committed; fetch it from `http://purl.obolibrary.org/obo/mfoem.owl`.
