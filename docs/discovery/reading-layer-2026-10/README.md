# Reading layer — discovery (2026-10-18)

**Discovery only. Not normative; nothing here is in `schema/`, `examples/` or the draft schema build.** No API call was made for any file in this folder.

Runs 1–3 (`../ontology-crosswalk-2026-10/`) scored which EDM values different extractors produce from the same text. This folder asks where in the text a value comes from and what licenses it when the text does not say it: the *given-off* signal (Goffman) — the delayed reply, the subject that keeps returning, the tense that does not match a stated death. It is the groundwork for a run that scores spans and cues rather than values.

| File | What it is |
|---|---|
| `literature.md` | The sign lineage: Darwin 1872, Freud's parapraxis, Goffman's given / given-off, Ekman's leakage, Grice's implicature, Sacks / Schegloff / Jefferson on silence and delay, Labov's evaluation devices, Pennebaker's function words — what each contributes to a reading layer and what each lacks for text-only, model-mediated conversation; a summary table and three consequences (every cue needs a stated norm; most textual cues license process, not content; the model is a sign-producer reading signs) |
| `cues-v1.md` | A catalogue of 35 unsaid-signal patterns (`rl:<slug>`, proposed vocabulary `cues/v1`) in seven families — timing, quantity, manner, repetition, person, relation, evaluation — each with a definition stated as a departure from a norm, its lineage or an EDM flag (6 have no named source for the written form), one synthetic example with the span marked, the unit an extractor must point at, and the labels it typically licenses (process vs content); the rules every reading must obey |
| `schema-sketch.md` + `reading.fragment.json` | An additive, optional, migration-neutral top-level `reading` block: `source` (sha256, length, normalisation, optional turn index), per-field `evidence` (quoted spans with code-point offsets, keyed by field path like `telemetry.field_confidence`), and `readings` (cue codes, spans, field, licensed label, licence strength, norm, flags, extractor, whether the field took it up). Draft-07 fragment compiles under ajv; worked synthetic example; open questions (admit to the composites, seal or not, quote privacy, SKOS) |
| `experiment-plan-run4.md` | Pre-registration of run 4 — **not frozen, not run**: 50 of the 150 public texts (sampler written and tested), three voters (Sonnet 5.5, Gemini 4 Argon, gpt-6.1-sol), three repeats, the Extended 28 with evidence and readings; measures M1 span overlap (character Jaccard) per field, M2 cue agreement κ, M3 cue → label stability and the over-reading rate, M4 a reconciliation arm on the interpretive tier (each voter sees the others' modal answers with spans, one revision pass, re-scored, with evidence retention); predictions P1–P6; ≈ USD 24–28 under a USD 30 stop; a private-arm protocol for the founder's archive, deferred until Anthropic direct access is restored and never through a gateway, with a sampler that stores no text |
| `scripts/sample_run4.py` | 50 of 150 by corpus arm (17 / 17 / 16), seed 20261019, from the run-3 manifest (ids and sha256 only); tested, prints the ids |
| `scripts/sample_private.py` | The private-arm sampler (§9.1 of the plan): archive root → manifest of sha256 / length / year / tercile written **outside** the repo; no text stored; **written, not run** on any archive (tested on three synthetic files in a scratch folder) |
